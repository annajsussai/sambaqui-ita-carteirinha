# sambaqui-ita-carteirinha
App full-stack (Node.js/Postgres) para emissão de carteirinhas digitais do Cursinho Sambaqui. Possui login seguro via RG e Data de Nascimento, proteção contra ataques brute-force (Rate Limit) e geração de imagem PNG com timestamp e QR Code para uso dos alunos. Ideal para deploy no Railway com foco em segurança e praticidade mobile.
